# Listing 上架检查清单（SOP）

## 上架前必查

- [ ] 标题 ≤ 200 字符，含品牌+品类+核心词
- [ ] 5 条 Bullet，每条 ≤ 500 字符
- [ ] Search Terms 不重复标题词，≤ 250 bytes
- [ ] 无禁用词：best, free, #1, guarantee, cheapest
- [ ] 无 HTML / 特殊符号堆砌
- [ ] 主图白底，产品占 85% 以上
- [ ] 电子产品：续航、接口、防水等级等技术参数写清楚

## 合规

- [ ] 无侵权品牌词（BMW, Mercedes 等需用 compatible with 格式）
- [ ] 无绝对化承诺

## 发布后

- [ ] 24h 内检查是否被 suppress
- [ ] 记录 CTR/CVR 基线
