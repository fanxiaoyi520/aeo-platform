# Amazon Listing 规范（公开摘录摘要）

## 标题（Title）

- 最多 **200 个字符**（含空格）
- 包含核心关键词：品牌 + 产品类型 + 关键属性
- 禁止全大写、禁止特殊符号堆砌
- 禁止促销用语：free shipping, best, #1, guarantee

## 五点描述（Bullet Points）

- 每条最多 **500 个字符**
- 共 5 条，突出功能、场景、差异化
- 句首大写，不用结尾标点
- 禁止 HTML 标签

## Search Terms

- 最多 **250 bytes**（非字符）
- 不重复标题和 Bullet 中已有词
- 用空格分隔，不用标点

## 汽摩配 / 诊断仪类目补充

- 必须标明 OBD2 / EOBD 兼容性（如适用）
- 电压、接口类型（OBD-II 16-pin）应写清
- 避免「适用于所有车型」等绝对化表述
