# 架构决策记录（ADR）

> 重大技术决策的追加式记录。流程见 [`../04_ARCHITECTURE_STANDARDS.md`](../04_ARCHITECTURE_STANDARDS.md) §11。

## 何时写 ADR

- 更换技术栈组件
- 拆分 / 合并服务
- 更改 API 版本或响应格式
- 更改数据库 Schema 的破坏性迁移
- 其它影响多模块、难以从代码 alone 还原的取舍

## 如何新增

1. 复制 [`0000-template.md`](0000-template.md) 为 `NNNN-short-title.md`（四位序号递增）
2. 填写背景、决策、后果；状态先为 `提议`
3. 维护者批准后改为 `已接受`；被取代时改为 `已废弃` 并链到新 ADR
4. 在本页「索引」表追加一行
