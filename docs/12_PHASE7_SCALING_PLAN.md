## 4. 技术决策

### 4.1 缓存策略

| 考量 | 决策 |
|------|------|
| 缓存层 | Redis（已集成） |
| 缓存对象 | Listing 模板、平台规则、热点商品数据 |
| TTL | 5min（规则）/ 1min（商品）/ 1h（模板） |
| 失效策略 | Write-through + 手动失效 |

### 4.2 熔断器

| 考量 | 决策 |
|------|------|
| 库 | `tenacity`（已用）+ `pybreaker` |
| 触发条件 | 5 次失败 / 60s 窗口 |
| 恢复策略 | 半开状态探测，30s 后重试 |
| 降级 | 返回 mock 数据或缓存 |

### 4.3 多平台适配器

| 考量 | 决策 |
|------|------|
| 接口 | `PlatformAdapter` Protocol（统一方法签名） |
| 扩展 | 平台特有字段放在 `extra: dict[str, Any]` |
| 认证 | 每个平台独立凭证管理，统一加密 |
| 降级 | 每个平台独立 mock/real 切换 |

### 4.4 多语言支持

| 考量 | 决策 |
|------|------|
| 翻译 | LLM 翻译 + 人工审核（HITL） |
| 语言 | 英/德/日/西（首期 4 语言） |
| 本地化 | 平台规则本地化（禁用词、格式） |
| 存储 | 多语言版本关联（SKU + language） |
