## 你怎么查（不用记）

1. **打开本文件** `docs/SESSIONS.md` → 看「当前活跃会话」表  
2. **看 Cursor 对话标题** → 重命名为上表「登记人标签」  
3. **搞混了** → 在任意窗口说 **「搞混了」** 或 **「会话状态」**，Agent 读表 + 帮你对齐

---

## 搞混了怎么办（3 步恢复）

### ① 先别写代码

不确定角色的窗口**先停**，避免工人/总控抢同一目录。

### ② 任意窗口说「搞混了」

Agent 会汇总：

- `SESSIONS.md` 里谁登记了什么  
- `02_PROGRESS` 任务认领簿里 S3-01 / S5-01 谁占着  
- 建议每个 Cursor 标签该叫什么  

### ③ 对齐（二选一）

**轻量对齐（推荐）**

1. 你决定每个窗口最终角色  
2. 在该窗口说一句口令：`总控` / `领取空闲任务` / `验收`  
3. 把 Cursor 对话**重命名**成 `总控`、`工人-B`、`验收`  
4. 不用的旧窗口说 **「释放会话」** 或删掉

**彻底重置（全乱了）**

1. 只在**一个**窗口说 **「总控」** → 再 say **「重置会话登记」**  
2. 其他窗口逐个重新说口令  
3. 重命名所有对话标题  

### 快速对照（看标题就够）

| 对话标题 | 能说 | 不能说 |
|----------|------|--------|
| `总控` | 集成、改派、批准 MSx | — |
| `工人-B` | 继续 orchestrator | 批准里程碑 |
| `工人-D` | 继续 web | 批准里程碑 |
| `验收` | 验收、出报告 | 大改代码 |

## Agent 登记规则

听到口令后、写代码前：

1. 读本表；同角色已有 `active` 且非本人 → **提醒用户**「已有 {标签} 在跑」，询问是否接管  
2. 写入一行：`登记人标签` + `角色` + `active` + 时间 + 简述  
3. 工人：标签 = `工人-{Lane}`（与任务认领登记簿一致）  
4. 会话结束或用户说 **「释放会话」** → 改 `idle`

**禁止：** 工人/验收登记为 `总控`；验收登记开发任务到任务认领登记簿。
